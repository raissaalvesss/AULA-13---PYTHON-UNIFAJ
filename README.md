# Calculadora com Funções em Python

Este repositório contém uma atividade feita em Python usando funções para realizar operações matemáticas.

Arquivos presentes no repositório:
. calculadora.ipynb: arquivo principal da calculadora
.calc.py: arquivo com as funções matemáticas usadas no programa, como soma, subtração, multiplicação, divisão, potência e raiz quadrada.

A atividade envolve a utilização de funções, estruturas, entrada de dados e organização do código em arquivos separados.
